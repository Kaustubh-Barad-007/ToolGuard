# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The ToolGuard team takes security vulnerabilities seriously. We appreciate your efforts to responsibly disclose your findings.

If you discover a security vulnerability within ToolGuard, please do **NOT** open a public GitHub issue. Instead, please report it via one of the following methods:

1. **GitHub Security Advisory**: Navigate to the [Security Advisories](https://github.com/Kaustubh-Barad-007/ToolGuard/security/advisories) tab and click **"Report a vulnerability"**.
2. **Email**: Send detailed information to the project maintainer at `kaustubhbarad007@gmail.com`.

### What to Include

Please include as much information as possible to help us reproduce and fix the issue:
- Clear description of the vulnerability
- Affected component (`@toolguard/core`, `@toolguard/cli`, VS Code extension, or Web Dashboard)
- Reproduction steps or proof-of-concept
- Potential security impact

### Response Timeline

- **Initial Acknowledgement**: Within 48 hours
- **Assessment & Triage**: Within 5 business days
- **Patch Release**: As soon as verified and tested
